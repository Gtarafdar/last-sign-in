# Chrome Web Store listing — Last Sign-in

## Name

Last Sign-in

## Short description (≤132 characters)

See which sign-in method you used last time. Stored on your device, without passwords, emails, cookies, or tokens.

## Detailed description

Tired of guessing whether you used GitHub, Google, SSO, or email last time?

Last Sign-in remembers the **type** of sign-in method you chose on each website and shows a small LAST USED (or LAST SELECTED) label next to that option when you return.

**Privacy first**
- Does not read or store passwords, emails, cookies, or tokens
- Data stays on your device
- You enable the extension per site

**Helpful, not pushy**
- Click a sign-in button → we remember the method
- Confirm with “Yes, this worked” when you want LAST USED
- Fix mistakes in two clicks from the popup
- Optional Work / Personal labels

**Honest confidence**
- LAST SELECTED = you clicked it
- LAST USED = you confirmed it (or a safe success signal was detected)

No account required. No backend. No analytics in this version.

## Permission justifications

- **Storage:** Save which method you used on which site, plus your settings.
- **Active tab / scripting:** Place the reminder badge and detect method clicks only after you enable a site.
- **Optional host permissions:** Requested only when you choose to keep the extension active on a specific site.
