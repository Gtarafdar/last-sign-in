# Changelog

All notable changes to **Last Sign-in** are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.1.3] — 2026-08-03

### Added
- **Edit** on Options → Saved sites: change method and optional name/email label inline (same fields as popup manual save)
- Saves via existing `UPDATE_SITE_RECORD` path; edited rows show **Manual** status

## [0.1.2] — 2026-08-02

### Changed
- Wired mid-green icon into both `icons` and `action.default_icon` so the toolbar picks up the dark-mode-friendly mark

## [0.1.1] — 2026-08-02

### Changed
- Brighter toolbar icon (mid-green shell + light rim) so the squircle stays visible on dark Chrome themes

## [0.1.0] — 2026-08-02

### Added
- Initial public release: privacy-first Chrome MV3 extension
- LAST USED / LAST SELECTED badges when auto-detect can pin a button
- Manual mode with optional name/email reminder label
- Per-site enable, Options settings, local-only storage
- Landing page, README, and GitHub Releases zip install
